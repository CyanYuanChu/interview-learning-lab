# 面试算法模式索引

- 类型：面试算法模式索引
- 来源：[LeetCode 热题 100](https://leetcode.cn/studyplan/top-100-liked/)
- 使用位置：notes、skills/hot100-recall

| 模式 | 识别信号 | 首要不变量 |
|---|---|---|
| 哈希计数 | 需要快速判断出现次数或配对关系 | 处理当前元素前，表中保存已处理信息 |
| 双指针 | 两端收缩或同向扫描可以减少重复比较 | 指针移动后，已排除区间不再包含答案 |
| 滑动窗口 | 连续区间满足可增量维护的条件 | 窗口始终满足当前约束 |
| 单调栈 | 需要找下一个更大、更小或边界 | 栈内元素保持单调，出栈时完成结算 |
| 二叉树后序 DFS | 当前节点依赖左右子树结果 | 明确 dfs 返回给父节点的信息 |
| BFS 分层 | 题目关心距离、层数或最短步数 | 一轮只处理进入本层时已有的队列元素 |
| 回溯 | 需要枚举选择并撤销路径状态 | 进入分支前做选择，离开分支后恢复 |
| 动态规划 | 子问题重复且状态可复用 | 状态定义、转移和初始化彼此一致 |

这份索引只负责识别入口；具体题解放在 notes，题目来源放在 external。
