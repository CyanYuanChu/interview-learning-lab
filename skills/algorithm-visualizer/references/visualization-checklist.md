# Visualization Checklist

## Algorithm

- What invariant does each frame preserve?
- Which values change after each step?
- Can a learner predict the next state?
- Does the visualization distinguish local state from the final answer?

## Interaction

- Is there a clear start, pause, step, and reset behavior where applicable?
- Are invalid or oversized inputs handled?
- Can keyboard users reach and understand the controls?
- Does a reset remove all derived state?

## Delivery

- Can the page open without a build step?
- Are external assets necessary and documented?
- Does the app README state how to run and stop it?
- Has the shortest meaningful interaction been checked in a browser?
