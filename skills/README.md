| Skill | 触发场景 | 入口 |
|---|---|---|
| hot100-recall | 生成主动回忆题、评分和弱点复盘 | [SKILL.md](hot100-recall/SKILL.md) |

| repository-structure-audit | 检查目录边界和项目入口 | [SKILL.md](repository-structure-audit/SKILL.md) |

Skill 只描述可复用的任务能力；个人题解仍放在 notes，来源索引仍放在 references。
