# Mistake Taxonomy

| 类型 | 典型表现 | 复盘问题 |
|---|---|---|
| 状态定义错误 | 不清楚函数或 DFS 返回什么 | 这个返回值交给谁，代表什么 |
| 边界初始化错误 | 空节点、空数组或全负数时出错 | 基础值是否与状态定义一致 |
| 合并方向错误 | 把局部返回值和全局答案混用 | 父节点需要单边贡献还是完整答案 |
| 访问顺序错误 | BFS 层边界或后序依赖被破坏 | 当前计算需要哪些子问题先完成 |
| 回溯遗漏 | 分支之间共享了上一次状态 | 进入和离开分支时分别修改什么 |
| 复杂度失控 | 在循环或递归中重复扫描 | 哪个操作可以用哈希或增量状态替代 |
| 表达不完整 | 只给代码，不说明思路 | 能否用一句话说清不变量 |
