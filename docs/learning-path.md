# 面试学习路径

## 1. 先建立模式识别

按数据结构和解题模式整理题目：

1. 数组与哈希；
2. 双指针与滑动窗口；
3. 栈与队列；
4. 链表；
5. 二叉树与二叉搜索树；
6. 图、回溯和动态规划。

每个专题先理解不变量，再记住典型题目。

## 2. 再训练面试表达

做题时固定说明：

- 题目要维护的状态；
- 选择该算法的原因；
- 关键边界；
- 时间和空间复杂度；
- 如何用一个小例子验证。

## 3. 用主动回忆代替重复阅读

完成一道题后，合上笔记回答：

- 函数或 DFS 返回什么；
- 当前状态如何由子状态合并；
- 空输入、重复值、负数或越界时怎么办；
- 如果改成迭代，额外需要保存什么。

## 4. 形成复盘闭环

每次练习保留三项结果：

- 一句话知识点；
- 一个最容易犯的错误；
- 下一次遇到相似题时的识别信号。

复盘结果进入 notes，稳定的分类规则才进入 references 或 skills。
