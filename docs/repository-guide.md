# 仓库目录规则

## 内容边界

| 内容 | 目录 |
|---|---|
| 个人思考、题解、错题 | notes/ |
| 官方资料、题单、模式索引 | references/ |
| 可复用的 Agent 任务能力 | skills/ |
| 可运行的练习或演示 | apps/ |
| 项目级规则和学习路径 | docs/ |

根目录只保留项目入口、贡献规则、版本控制配置和必要工具配置。

## 命名

- 目录和文件名使用小写 kebab-case。
- Skill 目录使用动词或能力名称，入口固定为 SKILL.md。
- 独立 app 必须有 README.md 和明确的启动方式。
- 同一份规则只维护一个来源，其他位置使用链接。

## 内容判断

- 记录一次个人理解：放 notes。
- 供多个地方稳定查阅：放 references。
- 需要模型按步骤执行：放 skills。
- 能被用户直接打开或运行：放 apps。

如果内容同时符合多个目录，优先拆分：把事实索引放 references，把个人推导放 notes，把执行流程放 skill。
